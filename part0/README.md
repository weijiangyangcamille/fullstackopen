### SPA 与 传统应用的不同
* **传统应用（MPA，多页应用）**：每次你点击链接跳去新页面、或者点击表单提交保存数据，浏览器都会向服务器**重新索要一份完整的 HTML 页面**。页面会经历销毁、白屏、再重新解析渲染的过程。
* **单页应用（SPA）**：浏览器从头到尾**只向服务器请求这唯一的一份 HTML 页面**（通常就是一个简单的空骨架，比如包含 `<div id="root"></div>`）。

---

### SPA 之后是怎么工作的？

既然只请求了一次 HTML，后续用户“跳转页面”或者“增删改查”时发生了什么？

1. **不再请求 HTML，只请求纯数据（JSON）**：
后续所有的操作，都是浏览器里的 JavaScript（比如 React/Vue）在后台悄悄发送异步请求（`fetch` 或 `axios`），向后端只索要或发送**极小体积的 JSON 数据**。
2. **本地动态切换视图（客户端路由）**：
比如你点击导航栏从“首页”跳到“个人中心”，浏览器根本没有去向服务器要 `user.html`。而是前端的 JavaScript 拦截了点击，检测到 URL 变成了 `/user`，直接把页面中间的组件擦掉，动态换上了个人中心的组件。

这也是为什么 SPA 体验丝滑得像一个手机 App，完全没有传统网页跳转时那种短暂的白屏和闪烁。
